# FinDash - 頂級加密貨幣工作區 (Premium Crypto Workspace)

## 📖 專案介紹
**FinDash** 是一個專為專業加密貨幣交易者與愛好者設計的現代化、深色主題金融儀表板。本專案展示了一個高質感的用戶介面，採用了「玻璃擬態 (Glassmorphism)」美學、動態數據視覺化，以及靈感來自頂級金融平台的乾淨模組化排版。

## 🛠 使用技術
本專案使用標準網頁技術構建，並專注於現代設計趨勢：

- **HTML5**: 提供語意化結構，確保可訪問性與 SEO。
- **CSS3**: 
  - 大量使用 CSS 變數 (`var(--name)`) 進行主題管理。
  - 使用 Flexbox 與 Grid 佈局架構。
  - 玻璃擬態效果 (backdrop-filter)。
- **JavaScript (原生)**: 
  - 處理標籤切換與互動狀態管理的邏輯。
- **外部函式庫**:
  - [Chart.js](https://www.chartjs.org/): 驅動帶有自訂漸層效果的互動式比特幣價格圖表。
  - [Lucide Icons](https://lucide.dev/): 提供清晰、輕量級的 SVG圖示。
- **字體**: 
  - Google Fonts 的 `Inter` (用於介面元素) 與 `JetBrains Mono` (用於金融數據/數字)。

## 🚀 如何執行
由於本專案由靜態前端檔案組成，不需要伺服器或安裝步驟：

1. **找到資料夾**: 在您的電腦上打開 `Week 14` 資料夾。
2. **開啟檔案**: 找到 `index.html`。
3. **啟動**: 雙擊 `index.html`，即可以預設瀏覽器（Chrome, Edge, Firefox 等）開啟。
